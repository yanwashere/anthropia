CRM Widget

Встраивание формы заявок в ваш сайт

О виджете

CRM Widget - это Web Component, который позволяет встроить форму заявок прямо на ваш сайт без необходимости создания отдельной страницы.

Основные возможности:

  • Простое встраивание в любой сайт
  • Встроенная валидация формы
  • Автоматическое создание заявок в CRM
  • Полная кастомизация внешнего вида
  • Работает на любом фреймворке
  • Поддержка локализации
  • События для отслеживания

Быстрый старт

Добавьте 3 строки кода на вашу страницу:

<!-- Место для виджета --> <crm-widget></crm-widget> <!-- Скрипт --> <script src="crm-widget.js"></script>

Виджет автоматически подключится к CRM API и будет создавать заявки в системе.

API URL: http://localhost:5000/api
Метод: POST /tickets/create

Попробуйте виджет

Параметры виджета

api-url - URL API сервера (по умолчанию: http://localhost:5000/api)

<crm-widget api-url="https://api.example.com/v1"></crm-widget>

title - Заголовок формы

<crm-widget title="Свяжитесь с нами"></crm-widget>

subtitle - Подзаголовок/описание

<crm-widget subtitle="Мы ответим в течение 24 часов"></crm-widget>

Обработка событий

Виджет отправляет событие при успешной отправке:

document.querySelector('crm-widget') .addEventListener('ticket-submitted', (event) => { console.log('Заявка создана:', event.detail.ticketId); console.log('Данные:', event.detail.data); // Ваш код... });

Вы можете использовать это для отправки уведомлений, редиректа или любых других действий.
