# CRM - Система управления заявками

Простая и функциональная система управления заявками с авторизацией модераторов.

## Функционал

✅ **Регистрация и авторизация модераторов** - Создание аккаунтов с хешированием паролей
✅ **Управление заявками** - Создание, просмотр, назначение, изменение статуса
✅ **Статусы заявок** - Новая, В работе, Решено, Закрыто
✅ **Простой интерфейс** - Ничего лишнего, всё интуитивно
✅ **Локальная база данных** - SQLite, всё хранится локально

## Быстрый старт

### 1️⃣ Запустить backend

```bash
cd crm/server
npm install  # уже установлены
npm start
```

Сервер запустится на `http://localhost:5000`

### 2️⃣ Запустить frontend

В новом терминале:

```bash
cd crm/client
node server.js
```

Frontend откроется на `http://localhost:3000`

## Как использовать

### Для модератора:

1. **Регистрация** - Создай аккаунт (имя, email, пароль)
2. **Вход** - Войди в систему
3. **Просмотр заявок** - Переходи между табами:
   - **Все заявки** - Видишь все заявки в системе
   - **Мои заявки** - Видишь только назначенные тебе
   - **Новая заявка** - Можешь создать заявку (от клиента)

4. **Работа с заявкой** - Нажми на заявку и:
   - Нажми "Принять заявку" - Назначить себе
   - Нажми "В работе" - Указать что работаешь
   - Нажми "Решено" - Заявка решена
   - Нажми "Закрыто" - Закрыть заявку

### Для тестирования:

**Демо-аккаунт:**
- Имя: `demo`
- Пароль: `password123`

Или создай свой аккаунт при регистрации.

## Технологический стек

- **Backend:** Node.js + Express
- **Frontend:** Vanilla JavaScript (SPA)
- **База данных:** SQLite
- **Аутентификация:** JWT + bcryptjs
- **Стили:** CSS Grid & Flexbox

## API Endpoints

### Auth
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Логин
- `GET /api/auth/profile` - Профиль (нужен токен)

### Tickets
- `POST /api/tickets/create` - Создать заявку
- `GET /api/tickets/all` - Все заявки (нужен токен)
- `GET /api/tickets/my` - Мои заявки (нужен токен)
- `GET /api/tickets/:id` - Одна заявка (нужен токен)
- `POST /api/tickets/:id/assign` - Назначить себе (нужен токен)
- `POST /api/tickets/:id/status` - Изменить статус (нужен токен)

## Примечания

- Данные хранятся в `crm/server/crm.db` (SQLite)
- JWT токен хранится в localStorage браузера
- Система работает в режиме SPA (Single Page Application)
- Все пароли хешируются через bcryptjs
