# 🚀 Anthropia CRM - Быстрый старт

## Для macOS - Одна команда запускает всё

### 📋 Требования

- **Node.js** 14+ (скачай с https://nodejs.org/)
- **macOS** (скрипт оптимизирован для Mac)

### ⚡ Быстрый старт (одна команда!)

```bash
# 1️⃣ Перейди в папку проекта
cd ~/path/to/anthropia

# 2️⃣ Запусти скрипт
./start.sh
```

**Вот и всё!** 🎉

Скрипт автоматически:
- ✅ Проверит Node.js и npm
- ✅ Установит зависимости
- ✅ Откроет 3 терминальных окна для сервисов
- ✅ Запустит все сервисы
- ✅ Откроет браузер на http://localhost:8000

---

## 🌐 Что откроется

После запуска будут доступны:

| Сервис | URL | Описание |
|--------|-----|---------|
| **Основной сайт** | http://localhost:8000 | Сайт Anthropia с CRM виджетом |
| **Панель модератора** | http://localhost:3000 | Личный кабинет для обработки заявок |
| **API Backend** | http://localhost:5000/api | REST API для данных |

---

## 💼 Как использовать

### 1️⃣ На основном сайте (localhost:8000)

- Прокрути вниз в секцию "связаться с нами"
- Заполни форму записи на консультацию
- Отправь — данные сразу уходят в CRM

### 2️⃣ В панели модератора (localhost:3000)

- **Зарегистрируйся** или **залогинься**
- Перейди в "Все заявки" — вижишь только что отправленную?
- Нажми на заявку → "Принять заявку" → выбери статус → сохрани

### 3️⃣ Каждый сервис в отдельном окне

- **Terminal 1**: Backend (порт 5000)
- **Terminal 2**: CRM Panel (порт 3000)
- **Terminal 3**: Main Site (порт 8000)

Каждое окно показывает логи сервиса. Закрой окно → сервис остановится.

## 🐛 Если что-то не работает

### Backend не запускается?
```bash
cd crm/server
npm install
npm start
```

### Frontend не работает?
```bash
cd crm/client
node server.js
```

### Основной сайт не открывается?
```bash
node server.js
```

### Проверить все сервисы:
```bash
curl http://localhost:5000/api/health  # Backend
curl http://localhost:3000/            # Frontend
curl http://localhost:8000/            # Main Site
```
